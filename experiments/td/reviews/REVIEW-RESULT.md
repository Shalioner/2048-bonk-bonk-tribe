## Ключевая граница: selected0

Повторно прочитаны три selected BONKTD01 файла: metadata episodes0, bias(0.5,0.5,0.5), все веса0, одинаковые payload побитно. Общий parameter SHA:

```text
76858f880e6c5408fcae57e7b707ca77dd553ba522f1edaf1865fae70a0f9379
```

Поэтому этот контроль **не является сравнением разных обученных MC/TD моделей**. Он сравнивает heuristic с выбранной исходной нейтральной оценкой; названия mc_teacher/td_teacher обозначают ветви происхождения checkpoint, а не разные выбранные функции. Различия moves/time между одинаковыми evaluator не являются свидетельством эффекта алгоритма обучения. Их подробная причина этим аудитом не исследовалась.

Обученные ненулевые веса были получены, но отклонены validation — это отдельно подтверждено REVIEW-TRAINING.md. Здесь нельзя объявить победу TD-обучения, эквивалентность методов обучения или общий отрицательный вывод о TD/ML. Показан отрицательный итог конкретного выбора по этому протоколу.
