# Адаптация TD-обучения для Bonk

Новая ветка `local/strategy-td-port-20261102` от45fd360. Прежние MC-результаты,
их измеренный worktree и рабочая папка бота сохранены. Телефон/ADB не используются.

Цель — перенести реальное пошаговое обучение из TDL2048 и измерить, улучшит ли
оно игру с тремя несливающимися11. Оригиналы донора a99f620 и MIT-лицензия
сохранены в vendor/tdl2048-original с SHA. Переносимая часть — n-tuple update,
симметрии и последовательность TD(0). Стандартные merge-score, слияния и90/10
не переносятся: остаются правила и таблица появлений Bonk.

Новый формат BONKTD01 отделён от прежнего MC BONKVAL1. Оба доступны через
явный `--value-model PATH`; по умолчанию модель не включается, политикаlegacy
не переключается. У TD clipped-linear value, goal1/loss0, nonterminal rewards0.
Оценка не считается калиброванной вероятностью. Подробнее: TD-PORT-API.md.

## До новых данных

План зафиксирован в experiments/td/plan.json. Inventory охватывает1205
доступных JSON,426 различных прежних seed; ошибок чтения нет. Новые диапазоны
между собой не пересекаются, кроме намеренно общих training seeds для методов.
Неизвестные внешние прогоны не объявляются проверенными.

- 4096 train-only игр создают пул reachable start states с одной/двумя11;
  выбираются первые64 уникальных состояния каждой стадии без учёта исхода.
- MC и TD-teacher получают одинаковые seeds, starts, teacher/epsilon и число
  эпизодов. Проверяется digest траектории. Различается способ обновления value.
  Teacher фиксирован, его epsilon0; exploration0.05 применяется только в selfplay.
- TD-selfplay начинает с2048 teacher-эпизодов, затем выбирает действия собственной
  моделью с exploration. Его распределение данных отличается: сравнение с MC
  не объявляется изоляцией одного фактора.
- После2048 эпизодов половина starts полные, четверть — стадия1, четверть —2.
  Это curriculum, а не новые независимые полные игры. Counts разделяются.
- Validation192 продолжения — настройка checkpoint/остановки. Начальные cap
  состояния общие с train pool, поэтому независимым контролем это не называется.
- Проверки после2048/8192/16384/32768/65536/131072 эпизодов. Остановка после
  двух неулучшений, минимум трёх checks. Если достигнут предел с ростом,
  фиксируется budget-limited, а не достигнутое плато.
- Отбор24 новых seed сравнивает ручную эвристику, старый MC и три новых arm.
  Замораживается один TD. Контроль60 новых seed сравнит его с heuristic и
  matched MC при одинаковом верхнем бюджете10мс/ход; два парных p<=.025 нужны
  для совместного подтверждения. Победы пересчитываются по конечным полям.

И выбор checkpoint, и stopping используют только validation; screen/holdout
не участвуют в обучении. После начала любого evaluation новый fit запрещён
общим маркером, включая нестандартный output. Limit откатывает TD-эпизод и
останавливает этап; его нельзя записать как проигрыш. Сохраняются источники,
реальные binary/model SHA, все кандидаты, завершённые партии и отрицательные
результаты. Суммарный choose wall и расход на ход отделены от номинального
бюджета. Из короткого контроля не делается вывод о победах при10с.

## Состояние

Нативный обучатель и runner интегрированы;121 общий тест и21 тест runner
прошли. Независимые model/core и cycle reviews завершены; два найденных
крайних случая freeze/output исправлены до данных.

Первый pool512 завершён:64 уникальные позиции стадии1 и8 стадии2, limit0.
До любого обучения/validation/screen/holdout источник расширен до4096 ради
разнообразия исходных cap2-позиций. Решение основано на размере пула, не
выборе победивших источников. Старый файл сохранён как pilot-pool-512.json,
старый build — вне worktree. Первые512 seed намеренно повторяются как
training-only prefix; их нельзя считать новым независимым контролем.

Pool4096 завершён:64 cap1/59 cap2,4096 loss,0 limit,0 updates.
Префикс512 совпал с пилотом по всем полям, кроме времени исполнения.

Все три arm прошли по16384 эпизода (49152 суммарно). В каждом arm9216
полных стартов,3584 cap1 и3584 cap2. Matched teacher дал17 побед только из
cap2; TD-selfplay не выиграл. Все16384 matched траектории совпали, включая
конечные поля, ходы и digest. Лимитов нет.

Для каждого arm выполнены192 validation продолжения после0/2048/8192/16384
эпизодов:2304 суммарно. Все метрики(full,cap1,cap2) равны(0,0,0).
По правилу earliest-on-tie выбран **нулевой checkpoint: необученные V=.5**.
Три последовательных неулучшения удовлетворяют заданному локальному плато.
Обученные веса сохранены, но отбор их отклонил; дальнейшее сравнение не будет
выдаваться за демонстрацию силы обученного TD. Оба завершённых checkpoint
повторно открыты через строгий `--resume` без новых эпизодов.

Это ограничение данного опыта, а не вывод о бесполезности TD. Validation
проверяет greedy learned поведение, тогда как итоговый поиск использует
expectimax; нулевые метрики не различают кандидатов. Редкая целевая награда,
слабый учитель, четыре4-tuples и такой отбор остаются гипотезами причин,
не изолированными объяснениями. Полные данные:experiments/td/training-summary.json.

## Воспроизведение

Команды выполняются в этом сохранённом worktree. Источники и пути входят в
fingerprint; перенос абсолютных путей или пересборка не считаются `--resume`.
Для уже завершённого этапа нужен `--resume`; модель/данные не перезаписываются.

```sh
rtk proxy sh vendor/build.sh
rtk proxy python3 experiments/td/run.py build
rtk proxy python3 experiments/td/run.py pool
rtk proxy python3 experiments/td/run.py train --group matched
rtk proxy python3 experiments/td/run.py train --group selfplay
rtk proxy python3 experiments/td/run.py screen
rtk proxy python3 experiments/td/run.py freeze
rtk proxy python3 experiments/td/run.py holdout
rtk proxy python3 experiments/td/run.py finalize
```

После начала screen общий marker запрещает новое обучение/сборку. Timed игры
выполняются последовательно; обучение, сборки и тяжёлые проверки с ними не
совмещаются. Заморозка до holdout сохраняет SHA фактических библиотек, всех
моделей, данных и исходников. Ресурсы обучения отдельно зафиксированы в
experiments/td/training-resource-usage.txt; это не RAM запущенного телефонного
бота и не стоимость одного хода.
