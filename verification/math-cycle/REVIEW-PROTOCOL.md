# Предданное независимое ревью математического runner

Проверен новый runner и протокол commit `989477a` поверх pure cleanup `ed977c9` и benchmark routing `8a2cbc0`: `experiments/math/{run.py,plan.json,seed-inventory.json,.gitignore}`, `test_math_cycle.py`, описание в MATH-IMPLEMENTATION.md. На момент первичной проверки actual build manifest, screen, finalist, control и summary отсутствовали. Исходники и данные не менялись. Полные партии, обучение, сборки и общий testsuite не запускались.

## Подтверждённый P2: verifier принимает неполную SHA-печать freeze

`run.py:380–388`: проверяется только непустой `hashes` и значения перечисленных SHA, но отсутствует проверка обязательного точного набора файлов, сформированного writer в `freeze` (`:370–374`). Удаление обязательных ключей превращает обещанную печать raw screen в необязательную.

Воспроизведено на временном fixture из существующего `test_math_cycle.py`, только с mocked games/native bytes:

1. Завершить synthetic screen и вызвать `freeze()`: writer записывает **26** hash paths.
2. Сохранить в `hashes` единственную штатную пару `benchmark.py → SHA`; `verify_freeze()` успешно возвращает такой файл.
3. Увеличить `screen["games"][0]["positions"]` на 1, атомарно записать raw screen; `verify_freeze()` снова успешен. Изменение не входит в агрегат `summarize`, поэтому повторный расчёт table/selection его не замечает.

Граница finding: подмена generated native в том же fixture отклоняется `check_build` с «Изменён фактический бинарник/исходник empty_r1»; изменение bot.py — с «Build sources несовместимы». Следовательно, это дефект строгой полноты freeze и неизменности raw screen, а не доказательство обхода независимой привязки source/native или изменения штатного выбора. После начала control его header дополнительно фиксирует SHA finalist; нормальный writer сам создаёт полный список. Finding передан координатору до build/данных.

Минимальная мера: один общий builder обязательных freeze paths для writer/verifier; точное равенство keyset и проверка всех SHA. Регрессии должны отклонять сокращённый manifest и изменение raw telemetry после freeze. Решение о приёмке и исправлении остаётся у координатора.
