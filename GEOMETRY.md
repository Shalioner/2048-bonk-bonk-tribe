# Структурная эвристика без ML

Ветка local/strategy-geometry-20261102 от08b8b95. Рабочая предыдущая версия,
её источники и опыт31/60 против32/60 (p=0.5) сохранены в2048-math-20261102.
Новые улучшения проверяются отдельно: старые контрольные seed раскрыты.
ML-оценок, обучателей, весовых файлов и внешних AI-вызовов в решателе нет.
Модель появления плиток и обновление частот наблюдений остаются моделью среды.
Телефон, ADB, runtime merge-game-bot и чужой main не меняются.

Следующий цикл меняет структуру оценки, а не только глобальные веса:

1. Сегментная монотонность. Строка разделяется несливающимися плитками≥11;
   направленность каждого доступного отрезка оценивается отдельно. Это мягкий
   признак: CAP подвижны, они не объявляются постоянными стенами. Смешение с
   прежней монотонностью0.5 или1. Строки без CAP сохраняют прежнюю формулу.
2. Геометрия оставшегося пространства. Число ортогональных рёбер между клетками
   без CAP сравнивается с наилучшим при таком же количестве CAP. Штраф2000
   или4000 за недостающее ребро. Это soft proxy, не запрет ходов и не loss.
3. Риск немедленной блокировки. Только при двух11 и≤3 пустот вычисляется точная
   вероятность отсутствия legal move после одного spawn в принятой модели.
   Неотрицательная базовая оценка умножается на(1-strength×risk), strength0.5
   или1. Goal после spawn не считается loss. Отрицательная шкала старого
   решателя и best=0 не меняются; они не смешиваются с этим опытом.

Каждый вариант включает один механизм; комбинаций нет. Цель3×11 остаётся1e9,
переходы/кэш/планировщик неизменны. №1 меняет только предрасчёт строк, №2 требует
lookup по маске, №3 использует закрытую формулу риска без перебора ходов.
Поэтому качество будет сравниваться при общем верхнем бюджете10мс, а actual
wall/ход и достигнутая глубина будут сохранены отдельно. Старый счётчик positions
не включает арифметику новых признаков.

Независимое исследование seams подтвердило: старый cutoff завершает afterstate
до spawn; немедленная блокировка может не попасть в листовую оценку. Польза
исправления на полных играх пока не измерена. Все три направления — гипотезы.

До реальных партий нужны проверки формул, всех8 симметрий, geometryLUT, корректной
обработки goal/spawn/loss, cache vs reference и фактических build/SHA. План отбора,
stop criterion и отдельные свежие seed фиксируются до данных. Будет различаться
local plateau от исчерпания ограниченного списка, без подбора по контролю.
